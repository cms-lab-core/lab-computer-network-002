# Хост как сетевой узел

Два Linux/netshoot-хоста соединены напрямую через `eth1`.

В работе студент:
- отличает link state от IPv4 state;
- настраивает адрес / prefix и MTU;
- наблюдает автоматически появившийся connected route;
- создаёт реальный ICMP-трафик и наблюдает neighbor table;
- сохраняет capture через `%%capture_traffic`;
- проходит CHECK;
- удаляет IPv4 только на `pc2`, сравнивает исправный link с неисправным L3 и восстанавливает состояние.

`eth0` — management plane платформы. Его не изменяем.
