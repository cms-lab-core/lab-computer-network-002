# Computer Networks 002

Лабораторная работа **«Хост как сетевой узел»**.

Студент собирает модель состояния Linux-host: `link → address/prefix → connected route → neighbor → reachability`, проверяет её на реальных `pc1` / `pc2`, затем намеренно ломает только L3-состояние и диагностирует последствия.
